# 冒険の経路と現在地（統合設計書 §15.2）

## この段階の計画

1. 通行可能な地形・経路の契約から、距離と経路種別を使って最小費用の行程を作る。
2. 行程、移動中の区間、出発日・到着日、最後に確認した地点を保存する。
3. 各区間の到着時に通行可否を確認し、遮断時は最後の確認地点から迂回または帰還する。
4. 帰路が閉ざされた場合は地点で待機し、日次の再確認で開通後に再開する。
5. 同席判定、地図人数、冒険の詳細表示、保存継続、死亡時の同行者位置を検証する。

既存グラフは小さく、標準ライブラリの `heapq` によるDijkstra法で十分なため外部依存は追加しない。
探索順は地点IDで固定し、経路計画に乱数を消費しない。グリッドへの代替は既存の移動トポロジーが
認める場合だけ使い、明示的な空の経路グラフを格子の隣接で通り抜けない。

## 状態と時間

区間費用は `distance * route.base_cost`、日数はその費用と保存済み基本間隔の積を切り上げる。
移動中は区間と残り日数を表示する。区間到着時に現在地点を更新し、終点へ達して初めて探索／帰還を解決する。
居住地 `residence_location_id` は保持し、`location_id` は最後に到達した地点とする。
移動中の同席判定には `World.character_presence_location_id()` を使い、両端どちらにも人数を計上しない。
出発地 `run.origin` はその冒険の帰還先であり、以後に人物の居住地を変更しても書き換えない。

期限と補給の初期予算は往復の経路費用＋基本間隔4回分の探索余裕を基準とする。
遮断や迂回で消費が増えても予算を無料で補充しない。期限は区間到着時に確認し、途中の瞬間移動は行わない。
区間途中で閉鎖された道は到着処理時に通過せず、最後の確認地点へ戻った扱いで再計画する。
正確な道上の座標や引き返し距離はこの離散モデルでは保持しない。

到達不能な目的地へ進み続けず帰還に切り替える。帰路もなければ現在地点で待機し、同じ遮断の記録を
毎日増やさず再確認する。死亡で遠征が終わる場合も、生存した同行者は居住地へ飛ばず最後の確認地点に残る。

すべての変更は既存の原子的適用に含める。途中地点の状態も復元対象とする。
到着した地点の訪問済み状態も同時に更新し、保存読込時だけ状態が変わることを防ぐ。
世界単体の復元では地点参照を検証し、人物も揃うシミュレーター復元時に人物位置との整合を検証する。
到達しなかった目的地へ探索進捗や訪問履歴を付けず、途中での死者の追悼は最後の確認地点に残す。
旧セーブに行程がなければ後付けの位置を捏造せず、既存の予定／旧進行方式で完了させる。

同席と地図が共有する現在地の問い合わせを一つ加えるため、`WorldActorMixin` の既存の公開メソッド数の
例外を13から14へ変更した。一メソッドだけのmixinへ分けても責務は減らないため、この入口を同じ場所に保つ。
他の複雑度上限は維持し、状態の検証と一ステップの計画はそれぞれのまとまった処理へ分離した。

## 残る範囲

目的地の支配勢力と通行権、救助対象の移動・失効、居住地の制度的な管理、道上での遭遇、実在庫からの
補給調達・飢餓ダメージ、救助や運搬の一周は別途接続が必要。§15全体の完了とは扱わない。
